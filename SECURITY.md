# Security policy

## Supported versions

LOBOT Lab is currently in early development. Security fixes are made on the
latest version of the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when
available. If private reporting is unavailable, open an issue that requests a
private contact channel without including exploit details or sensitive local
paths.

LOBOT Lab parses user-selected XML, INI, STI, COL, ACT, DAT, and SLF files.
Reports involving malformed input, unsafe file resolution, or unexpected access
outside the selected Data roots are especially valuable.
